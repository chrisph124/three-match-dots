# Journals

Chronological technical journals — session reflections and change analysis. They preserve
work history; they do not replace current `docs/` authority or a plan's own records.

- **Naming:** `YYYY-MM-DD-<slug>.md` (e.g. `2026-08-18-endless-reverts-to-the-plain-journey-look.md`).
- **One home per artifact type** — see the routing table in `CLAUDE.md` (Team Workflow).
