# Brainstorms

Accepted brainstorm contracts — the outcome/constraints/non-goals/acceptance record a
piece of work starts from, before a plan exists. Stateful pre-delivery records, **not**
evergreen authority (see `docs/` for that).

- **Naming:** `YYMMDD-HHMM-<slug>.md` (e.g. `260818-1943-project-governance-docs-tooling.md`).
- **Lifecycle:** a brainstorm feeds a plan under `plans/<YYMMDD-HHMM-slug>/`; it does not
  supersede `docs/` authority once the work lands.
- **One home per artifact type** — see the routing table in `CLAUDE.md` (Team Workflow).
