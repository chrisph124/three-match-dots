# Reports

Per-agent and per-phase output — brainstorm reports, code-review reports, progress reports.
Stateful pre-delivery records, not evergreen authority.

- **Naming:** `<type>-YYMMDD-HHMM-<slug>.md`, where `<type>` is the agent name or report kind
  (e.g. `brainstorm-…`, `code-reviewer-…`, `progress-…`).
- **`_archive/`** parks records after their work landed or was superseded — see
  `_archive/README.md`.
- **One home per artifact type** — see the routing table in `CLAUDE.md` (Team Workflow).
