# Lessons Learned

One-off retrospectives and post-mortems — what broke, why, and what to do differently.
Stateful records, not evergreen authority.

- **Naming:** `YYMMDD-HHMM-<slug>.md`.
- **Reusable lesson?** If a lesson will recur across tasks, promote it to a committed skill
  at `.claude/skills/<slug>/SKILL.md` (the step-6 mechanism in `CLAUDE.md` → Team Workflow);
  committed skills auto-load for every teammate. Keep only genuinely one-off notes here.
- **One home per artifact type** — see the routing table in `CLAUDE.md` (Team Workflow).
