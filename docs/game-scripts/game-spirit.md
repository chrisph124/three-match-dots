# Game Spirit

The emotional core we protect — what a player should _feel_. Downstream of the LOCKED tone words
in [`creative-bible.md`](../creative-bible.md); this file keeps the felt experience explicit so
mechanics and art can be checked against it.

> Pre-production ideation, not authority. The bible's tone words (_warm, tactile,
> calm-but-purposeful, handmade, uncluttered_) and anti-words (_harsh, neon, busy, glossy-plastic,
> aggressive_) are the boundary; this file elaborates the feeling inside it.

## The feeling

- **Endless:** _the calm/meditative state we want to sustain — what breaks it, what protects it._
- **Journey:** _the focused/adventurous "conquer the world" sense without turning stressful._

## Signals we're on-spirit

_Observable tells (in playtest, art review) that the spirit is intact — and the tells that it has
drifted "too far from origin" (the bible's anti-drift purpose)._

## Moments to author

_Specific beats (first link, a color-clear, closing a loop, finishing a country) and the emotion
each should carry._
